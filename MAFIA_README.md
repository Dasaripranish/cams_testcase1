# MA01 Modification Request Classifier

> Generated by MAFIA — Smart Agent Builder for CAMS

## Description
Identifies which of the 28 MOFSL account modification types a customer is requesting from free-text or structured input. Routes to the correct processing channel (Emod/CBOS/SRA+JIRA). Validates client eligibility. Returns required document checklist.

---

## What MAFIA Generated

### Tools (5 tools)
- `classify_modification_type()`: Identifies which of the 28 MOFSL modification types the customer is requesting from their free-text input
- `validate_client_eligibility()`: Checks CBOS account status, pending SRA tickets, freeze status before accepting any modification request
- `determine_channel()`: Maps modification type to correct processing channel (Emod/CBOS/SRA+JIRA) and returns processing SLA
- `get_document_checklist()`: Returns the complete list of required documents for a modification type per SEBI KYC guidelines
- `get_client_profile()`: Fetches basic client details from CBOS — name, segment, account type, registered contacts

### Workflow Phases → Business States
- **Phase 1: Request Intake** — Parse and understand the customer modification request
- **Phase 2: Classification** — Identify modification type from 28 MOFSL types
- **Phase 3: Eligibility Check** — Validate client account status and eligibility
- **Phase 4: Channel Routing** — Route to Emod, CBOS, or SRA+JIRA
- **Phase 5: Document Checklist** — Return required documents for the modification type

**State machine** (`src/workflow/states.py`):
```
INITIATED → REQUEST_INTAKE → CLASSIFICATION → ELIGIBILITY_CHECK → CHANNEL_ROUTING → DOCUMENT_CHECKLIST → COMPLETED
            ↘ OBJECTED (at any phase)
            ↘ REJECTED / CANCELLED (at any phase)
```

Business states tracked in DB:
- `REQUEST_INTAKE`: Request Intake
- `CLASSIFICATION`: Classification
- `ELIGIBILITY_CHECK`: Eligibility Check
- `CHANNEL_ROUTING`: Channel Routing
- `DOCUMENT_CHECKLIST`: Document Checklist
- `COMPLETED` / `OBJECTED` / `REJECTED` / `CANCELLED`
